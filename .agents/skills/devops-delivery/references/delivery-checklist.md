# Delivery readiness checklist

- Verify runtime, package manager, lockfile, outputs, environment, architecture, and hosting provider.
- Define quality, build, security, artifact, migration, deployment, smoke-test, and promotion stages.
- Pin dependencies/actions; set least permissions, timeouts, concurrency, cache keys, and retention.
- Document secret names and purposes without exposing values.
- Define health signals, alerts, owner, rollback trigger/procedure, and data recovery.
- Exercise configuration, container build, migration dry run, smoke test, restore, and rollback where feasible.
