# Code-quality checklist

- Inventory languages, generated files, boundaries, editors, CI, scripts, and tool versions.
- Assign ownership to formatter, linter, typechecker, test runner, boundary checker, and security scanner.
- Use one canonical command per check across local work, Nx, hooks, and CI.
- Verify ignores, overrides, caching, exit codes, baseline behavior, diagnostics, and CI runtime.
- Test representative valid/invalid files plus staged and full-repository execution.
