# Frontend feature checklist

- Define route, audience, primary action, permissions, dependencies, and ownership.
- Cover initial, loading, stale, empty, partial, error, offline, unauthorized, and success states.
- Assign URL, server cache, form, feature, and local state deliberately.
- Validate keyboard flow, focus restoration, announcements, headings, labels, contrast, zoom, reduced motion, and RTL.
- Validate narrow/wide layouts, long translations, Arabic shaping, dates, numbers, currency, and time zones.
- Test critical behavior, recovery, navigation, analytics, accessibility, and performance budgets.
